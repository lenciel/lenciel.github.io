作为我的重仓股，苹果在 AI 上的投入和节奏我一直觉得是最好的：反正我死死握住用户交互的入口，AI 谁家强先用谁的，然后默默搞端侧模型。

### A 社的爽文

快要上市的 A 社最近发了不少爽文，比如 16 号的这篇《[A 社在招聘上发生了什么变化](https://www.anthropic.com/research/employment-at-anthropic)》。

先说里面中规中矩很 A 社的结论。

首先是初级岗位大幅削减：

{% picture /downloads/images/2026_10/anthropic-employee-1.png --alt anthropic-employee-1.png %}\
<small> 图 1. 初级人员招聘下降</small>

初级技术招聘占比从 27% 暴跌至 9%，从而使得技术部门初级员工占比从 21% 降至 14%，并且整体员工里研发数量也从 61% 降到了 56%。

我自己看到这里想到的是，初级员工你们不培养就不培养，拿来当丰功伟业宣传是不对的。

而作为一家今年人数会涨了三倍要冲上市的公司，从比例上多招了一些销售实在是没啥好说的。而比例下降后，还有 56%，估计可以把大部分国内技术公司的研发负责人看哭。

{% picture /downloads/images/2026_10/anthropic-employee-3.png --alt anthropic-employee-3.png %}\
<small> 图 2. 各个岗位产出的增长</small>

同时产出肯定是大大增长了：比如研发的 commit 涨了五倍，开不开心？

怎么说呢，拿来衡量产出，commit 数作为参考指标勉强合格吧。但我估计今年全世界大部分软件公司的 commit 说不定涨了不止 5 倍（因为安全啊、测试啊这些做的可能不如 A 社）？我自己国庆都是七八个 repo 跳来跳去地 commit。

然后是一些略显鬼畜的结论，比如：

{% picture /downloads/images/2026_10/anthropic-employee-2.png --alt anthropic-employee-2.png %}\
<small> 图 3. Agent 和人的工时比拉开差距</small>

我不知道为什么人的工时和 Agent 的运行时间需要拿来比，也不知道 Agent 工作时长超过人类员工（A 社说从今年 3 月份开始超过的）有什么需要庆祝的。

在 AI 之前，我写的所有软件，只要在线上就 7x24 小时跑着，没跑着才是出问题了。我从来没想过我睡醒后要感叹一下，我的 Blog 服务器它又忙了一个通宵没睡，真是太厉害了。

一个靠谱点儿的分析好像应该是，机器干了这么多，人有没有因此多歇着或者多收获？不然 Agent 就算工时刷到了人的 100 倍，人还是很苦啊。

{% picture /downloads/images/2026_10/anthropic-employee-4.png --alt anthropic-employee-4.png %}\
<small> 图 4. 各个工种读 claude 的时间</small>

这是 A 社用来表达如今干活是 Agent 等人，人是最大瓶颈的主要依据，

图片的原标题，不是我编的，就叫「光是读 Claude 就把人类时间花光了（Reading Claude as a full-time job）」。

首先，AI 这么几倍速的产出，人只要还在负责，可不就得造成这个数据大涨吗？除非这个环节不用人参与了，不然就没什么大惊小怪的{% sidenote 'sn-id-1' '这个糊涂程度，约等于 Hinton 当年预测有了 AI 看片子，相关医生得失业：结果因为片子看得快了，相关医生不够用了。' %}。

其次，这张图应该可以把任何想要加入 A 社的正常人类劝退吧（当然，那边有笔快钱）。

当然，这个报告里面还是有一些话是实在的，但不在图里。比如说，人和人之间约开会时间，中位数增加了 20%。

这我是很能想象的。

当手中有了顶配模型，很多时候，解决什么问题变成了关键。

而一个组织里面，要解决什么问题才是对的，从来都那么神秘，那么让某些人想要不停开会。

祝各位领导别把 AI 给员工省下来的那点儿时间都拿来开会。

也祝 A 社顶着 CoreWeave 暴雷的压力，继续好好带美股跑完这波 AI 叙事。
